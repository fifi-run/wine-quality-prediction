# Dataset attribution

This project uses the red-wine subset of the UCI Wine Quality dataset.

Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009). *Wine Quality* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C56S3T

The official UCI record specifies the Creative Commons Attribution 4.0 International (CC BY 4.0) licence: https://archive.ics.uci.edu/dataset/186/wine+quality

The red-wine file contains 1,599 observations and is semicolon-delimited. Download it from UCI and save it as data/winequality-red.csv. Retain this attribution when redistributing or adapting the dataset.
